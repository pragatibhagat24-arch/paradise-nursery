# Paradise Nursery

Paradise Nursery is an online plant shopping application designed to make discovering and purchasing plants easy and convenient.

## Project Overview

The project aims to provide users with a simple platform to explore different varieties of indoor and outdoor plants.

## Technologies Used

- React.js
- JavaScript
- CSS
- Redux Toolkit

## Planned Features

- Attractive landing page
- About Us section
- Plant product listing
- Shopping cart
- Add, remove, and update product quantities.
